Entry for the [One Letter for Your Day](https://make.fun/c/u-puan-one-letter-for-your-day-e54e9c36) competition on make.fun.

## What it does

The program writes exactly one letter to `/output/entry.txt`:

```
M
```

One byte, no newline. The letter stands for the day-word **"meh"** — the honest word for a day that was neither good nor bad, just... meh.

## Run

```bash
python3 main.py
```

Verified locally: `/output/entry.txt` is exactly 1 byte, the single character `M`.
